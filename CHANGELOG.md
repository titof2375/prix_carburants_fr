# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-31

### Added
- Initial release
- Support for two GPS locations (Home and Phone)
- Configurable search radius
- Display top N fuel stations
- Support for all fuel types (Gazole, SP95, SP98, E85, GPLc, SP95-E10)
- Real-time data updates (every 10 minutes)
- Fuel price update dates included
- Full Home Assistant integration with config flow
